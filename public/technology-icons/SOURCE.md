# Technology icon sources

Local SVGs from Simple Icons, retained unchanged and rendered as monochrome CSS masks. No runtime hotlinks or icon package dependency.

- nextdotjs.svg, react.svg, typescript.svg, supabase.svg, postgresql.svg, playwright.svg, vercel.svg: https://github.com/simple-icons/simple-icons/tree/11.15.0/icons
- n8n.svg: https://github.com/simple-icons/simple-icons/blob/develop/icons/n8n.svg (downloaded 2026-09-13; local file pins the retrieved asset)
- LICENSE.md: https://github.com/simple-icons/simple-icons/blob/11.15.0/LICENSE.md

Technology names and categories come from the existing published CMS query, with the existing dictionary fallback unchanged. Unknown CMS technologies retain their names and use a neutral monogram, not a fabricated official logo. Brand marks identify technologies, not endorsements.
